> **Last reviewed:** 2026-11-16 · **Last updated:** 2026-11-16 · **Change:** minor (translated to English) · **Target:** local VSCodium 1.147.0 (VS Code `22d8dccf0f29`)

Where each part of the package (`01-app/VSCode-linux-x64/`) comes from in the source tree (`02-package-analysis/source/tree/`). Everything below was measured by comparing the two folders, and the commands are in each section.

A bundle gathers every module imported from its entry. So a snippet of `workbench.desktop.main.js` can come from any file in `src/vs/{base,platform,editor,workbench}`. To find which one, use the `find-minified-symbol` skill.

## Summary

The package is the source tree compiled and minified, plus what packaging adds:
- six `product.json` keys;
- three downloaded extensions;
- the runtime modules;
- the compile cache.

No part of the package was found without a traceable origin.
